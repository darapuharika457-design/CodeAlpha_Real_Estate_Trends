# Real Estate Market Trends Dashboard 

## 📊 Project Overview
An interactive Real Estate Market Trends Dashboard built using Power BI, 
analyzing California housing data to uncover pricing patterns, location 
insights, and market factors, as part of the CodeAlpha Power BI Internship.

## 📁 Dataset
- California Housing Prices Dataset (1990 Census)
- 20,433 district-level records with location, price, and demographic data

## 📌 Key Features
- Interactive Map visualizing median house value by location
- KPI Cards: Median House Value, Average Median Income, Total Districts
- Average Price by Ocean Proximity
- Income vs House Price correlation analysis
- House Age vs Value trend analysis
- Population vs Households analysis (Market Demand & Supply indicator)
- Slicer to filter by Ocean Proximity

## 🎯 Key Insights
- Median house value across California: $206.86K
- Districts on Islands show the highest average house prices
- Higher median income areas show a strong correlation with higher house prices
- House age has minimal direct linear impact on value, ocean proximity 
  and income levels matter more
- Population and households show a strong positive relationship, 
  indicating consistent household sizes across most districts

## 🎨 Design Approach
This dashboard uses a map-first layout with a warm earth-tone color 
palette (terracotta, gold, charcoal) — a deliberate departure from 
traditional KPI-grid dashboards, since location is the most important 
factor in real estate analysis.

## 🛠 Tools Used
- Power BI Desktop
- Power Query for Data Cleaning
- Map Visualizations
- DAX Filtering
